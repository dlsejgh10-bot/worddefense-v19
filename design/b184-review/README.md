## 속성 타격

기존 EL / ELV 값을 사용한다. 스킬 및 피해 패시브의 한 타격 피해를 기준으로 화상·독·기존 속성 효과를 적용한다. 스킬 물 강화는 실제 피해 배율을 적용하고, 연발의 3·6번째 발사와 장판의 적별 3틱을 판정한다. 빛 첫 타 기록은 평타와 스킬이 공유하며 공격 직업은 재충전으로 첫 타가 다시 발생하지 않는다.

어둠은 ELV.darkP 30/50/70/100%를 사용한다. 쇼타임은 각 발사별로 따로 판정한다. 그림자 타격은 원래 타격의 계산 완료 피해를 저장해 그대로 재현하며 다시 치명타나 복제 확률을 굴리지 않는다. 스킬에 어둠 중첩 피해를 추가하지 않는다. 지원 3직업은 이 새 경로에서 제외된다.
