# 선택한 주말 보상 UI 에셋

사용자 선택 이미지의 navy/cyan/lime 티켓형 스타일로 분리 생성했습니다. 생성 방식은 built-in image_gen이며 프롬프트는 ticket-prompts-v45.json에 있습니다.

- ticket-header-v45: 빈 주말 보상 제목판과 LP 아이콘.
- ticket-card-v45: 글자·보상·상태 버튼이 없는 빈 보상 카드.
- ticket-progress-v45: 정확히 6칸인 빈 고정 티켓 바.
- ticket-start-v45: 번개를 줄인 빈 시작 버튼판.

PNG는 생성 원본과 알파를 보존합니다. WebP는 보이는 영역을 크롭한 무손실 런타임 파일입니다. crop 좌표는 ticket-assets-v45.json에 기록했습니다.

글자와 수량을 이미지에 굽지 않습니다. 주말 보상, 1~6회, 받기·잠금·수령 완료, 남은 입장과 댄스 시작 문구는 메인 게임 GWTT 폰트로 실시간 렌더합니다. 통화·열쇠·강화석과 짧은 버튼판은 원래 게임 에셋을 재사용합니다.

실제 사용 코드: home/rewards-v45.js. 카드 6개만 가로로 움직이며 하단 6칸 바와 시작 버튼은 고정입니다. 댄스 시작 글자는 버튼 전체 가운데에 정렬됩니다.

화면 확인 PNG는 실제 composition.js와 rewards-v45.js를 네이티브 Canvas로 렌더한 것입니다. 2회 플레이/1회 수령/입장 1회 남음은 배치 확인용 상태이며 실계정 보상 기록을 바꾸지 않았습니다.
